# 老姐，26岁生日快乐

小猫儿送给老姐的生日礼物。

这是独立托管版本。所有照片、短片、背景音乐、样式和脚本均随站点提供，不依赖 Google 字体或 chatgpt.site。

静态入口为 `index.html`，资源路径均为相对路径，可部署到网站根目录或项目子目录。GitHub Pages 发布目录为仓库根目录。

手机入口为 `start.html`。默认预存24张适合手机屏幕的照片、两段短片和音乐，完整下载包约1.72MB。清晰原图通过相册的“查看原图”按需打开。

媒体合并下载，支持保存中断位置和 HTTP Range 续传；既有缓存会被复用，代码更新不会使未变化的媒体重新下载。GitHub 与 jsDelivr 两条下载线路竞争取得数据后选择先返回有效数据的线路；媒体包使用内容哈希校验。
